# Noor Dua Book

A premium, mobile-first digital dua book by **Altaf Shaikh**.

Phase 1 includes:
- Dua home library with search and categories
- Realistic book reader with swipe/page-turn feel
- Arabic Quran-style font + Roman Urdu + meaning + source
- Touch sound + haptic feedback (where browser/device supports it)
- Favorites
- Four realistic book themes
- Adjustable Arabic text size
- Professional Altaf Shaikh branding
- PWA-ready shell

Website first; Android APK after the web experience is finalized.
